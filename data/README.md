# Data

This project uses SSDD (SAR Ship Detection Dataset).

1. Download from the official repo: https://github.com/TianwenZhang0825/Official-SSDD
2. Extract so this directory looks like:

```
data/
  JPEGImages/       - SAR image chips
  Annotations/      - VOC-format XML bounding box annotations
```

Not committed to git (see `.gitignore`) — dataset is a few hundred MB.
